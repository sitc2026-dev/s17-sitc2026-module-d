# SwapLoop QR 模擬器（SPA bundle）

`swaploop-qr-emulator.js` 是 `<swaploop-qr-emulator>` 的獨立 IIFE 建置版本。請以一般 script 標籤載入。它會註冊 custom element，並內含 QR 渲染功能——請勿使用會 `import` `qrcode` 的未打包原始檔案。

React、Vue 與 Angular 範例、`service-url`，以及 QR 測試器路徑，請見 [`../handouts/handout-qr-emulator-integration.md`](../handouts/handout-qr-emulator-integration.md)。
