# SwapLoop QR emulator (SPA bundle)

`swaploop-qr-emulator.js` is the standalone IIFE build of `<swaploop-qr-emulator>`. Load it with a classic script tag. It registers the custom element and includes QR rendering — do not use the unbundled source file that `import`s `qrcode`.

See [`../handouts/handout-qr-emulator-integration.md`](../handouts/handout-qr-emulator-integration.md) for React, Vue, and Angular examples, `service-url`, and the QR tester path.
